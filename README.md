# kd-test-code

Пример Telegram-бота, который удаляет текст встречи из чата и отправляет её саммари.

## Запуск

1. Установите зависимости:

    ```bash
    pip install "python-telegram-bot[job-queue]" openai feedparser
    ```

2. Укажите токены и модель в файле `config.py` (или задайте переменные окружения `BOT_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL`).
   `meeting_summary_bot.py` автоматически импортирует эти значения — редактировать его не нужно.

3. Запустите бота:

   ```bash
   python meeting_summary_bot.py
   ```

В группе вызовите команду `/analyze_meeting`, пришлите текст встречи. Бот удалит команду и исходное сообщение, сообщит «Встреча обрабатывается...», затем отправит отчёт со структурой и блоками «Где дожал» / «Где не дожал» и удалит служебное сообщение об обработке. В начале отчёта добавляется строка «Отчёт о встрече … – ссылка». Между блоками отчёта вставляется пустая строка.

После первого вызова `/analyze_meeting` бот также начнёт ежедневно в 10:00 (Europe/Moscow) присылать три свежие новости по архитектуре и дизайну в этот чат. Для этой функции нужно установить библиотеку с поддержкой `JobQueue` (см. зависимость выше).

Получить подборку новостей прямо сейчас можно командой `/new_today`.

Чтобы бот мог удалять сообщения, дайте ему права администратора в чате. Остановить ожидание текста можно командой `/stop` — бот ответит «Анализ остановлен, жду нового запроса».

## Тестирование

1. Проверка синтаксиса:

   ```bash
   python -m py_compile meeting_summary_bot.py config.py
   ```

2. Функциональная проверка: запустите бота и отправьте текст встречи через Telegram. Для этого нужны действующие токены.
