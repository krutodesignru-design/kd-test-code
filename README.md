# kd-test-code

Пример Telegram-бота, который удаляет текст встречи из чата и отправляет её саммари.

## Запуск

1. Установите зависимости:

   ```bash
   pip install python-telegram-bot openai
   ```

2. Задайте переменные окружения `BOT_TOKEN` и при необходимости `OPENAI_API_KEY`.

3. Запустите бота:

   ```bash
   python meeting_summary_bot.py
   ```

В группе вызовите команду `/analyze_meeting`, пришлите текст встречи. Бот удалит исходное сообщение и пришлёт отчёт со структурой и блоками «Где дожал» / «Где не дожал».
