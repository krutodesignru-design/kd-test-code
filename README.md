# kd-test-code

Пример Telegram-бота, который удаляет текст встречи из чата и отправляет её саммари.

## Запуск

1. Установите зависимости:

   ```bash
   pip install python-telegram-bot openai
   ```

2. Укажите токены и модель в файле `config.py` (или задайте переменные окружения `BOT_TOKEN`, `OPENAI_API_KEY`, `OPENAI_MODEL`).
   `meeting_summary_bot.py` автоматически импортирует эти значения — редактировать его не нужно.

3. Запустите бота:

   ```bash
   python meeting_summary_bot.py
   ```

В группе вызовите команду `/analyze_meeting`, пришлите текст встречи. Бот удалит команду и исходное сообщение и пришлёт отчёт со структурой и блоками «Где дожал» / «Где не дожал».

## Тестирование

1. Проверка синтаксиса:

   ```bash
   python -m py_compile meeting_summary_bot.py config.py
   ```

2. Функциональная проверка: запустите бота и отправьте текст встречи через Telegram. Для этого нужны действующие токены.
